Einstellungen

Gemini-API-Key

Mit einem kostenlosen Key von Google AI Studio wird GPTProp zum echten KI-Assistenten. Kostenlosen Key holen ↗

Modell

Automatisch nimmt für maximale Geschwindigkeit immer das kleinste Gratis-Modell (Flash-Lite) und weicht nur auf größere aus, wenn es ausgelastet ist oder das Limit erreicht hat.

Spotify

Play, Pause, Weiter und Lautstärke funktionieren sofort. Damit GPTProp bestimmte Songs automatisch abspielt, einmalig einen kostenlosen Zugang anlegen: Spotify-Dashboard ↗ → „Create app“ → Name egal, Redirect URI http://127.0.0.1:8888/callback, „Web API“ anhaken → Speichern → Settings → Client ID und Client Secret hier einfügen.
